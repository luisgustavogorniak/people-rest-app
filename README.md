# People REST API

API REST desenvolvida com NestJS e TypeScript para gerenciamento de pessoas.

## Tecnologias

- NestJS
- TypeScript
- MongoDB
- Mongoose
- Jest
- Supertest

## Funcionalidades

- Criar pessoa
- Listar pessoas
- Buscar pessoa por ID
- Atualizar pessoa
- Excluir pessoa

## Endpoints

GET    /people
GET    /people/:id
POST   /people
PUT    /people/:id
DELETE /people/:id

## Execução

npm install
npm run start:dev
